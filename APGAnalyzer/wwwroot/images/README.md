# Brand assets

## `pmtac-logo.png`

The PMTAC logo as it appears in the top navbar.

**Required dimensions:** 38px tall (any width). The CSS scales width proportionally, so a 38×38 square or a 38×120 horizontal logo both work.

**Format:** PNG with transparent background recommended. The navbar is purple (`#6E50CD`), so the logo needs to read against that color — the PMTAC orange/blue/green logo from the HRMS app works perfectly.

**How to add it:**

1. Save the existing PMTAC logo (the one with the orange swoosh + "PMTAC" wordmark) as a PNG with transparent background.
2. Resize to ~38px tall if it's much larger.
3. Save it to this folder as exactly `pmtac-logo.png`.

If the file is missing, the layout falls back gracefully — the brand text still renders, just without the image.
